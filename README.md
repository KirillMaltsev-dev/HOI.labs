**Лабораторная J2 — синхронизированный доступ к списку**

Нужен JDK 21, сторонних библиотек нет

**Запуск**

Из корня проекта в PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

По умолчанию используется связанный список, 4 потока и задержки по 1000 мс внутри шага и между шагами

Вариант с ArrayList и своими задержками

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 --implementation array --threads 4 --inside-ms 100 --between-ms 100
```

Введённая строка добавляется в начало, пустая строка выводит список, Ctrl+Z и Enter завершают ввод в Windows

Строки длиннее 80 символов делятся на части, каждая часть добавляется в начало отдельно

**Как работает**

Сортировщики бесконечно проходят все соседние пары и сравнивают строки через compareTo, даже если список уже отсортирован

В linked используется свой односвязный список, при перестановке меняются ссылки на узлы, строки внутри узлов не меняются

Для шага блокируются предшественник и два узла пары в порядке от головы к хвосту, нужная позиция каждый раз ищется от головы с передачей блокировок, поэтому на проход получается O(n²) переходов

В array используется Collections.synchronizedList с ArrayList, сравнение, перестановка и внутренняя задержка выполняются под общим монитором

Между шагами блокировок нет, для вывода linked накапливает блокировки от головы до хвоста и копирует записи, затем освобождает их до печати, for-each обходит снимок через Iterable

Снимок может ждать текущий шаг с внутренней задержкой, прерывание освобождает и частично захваченные блокировки

**Сравнение**

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 --mode benchmark --size 100 --threads 4 --inside-ms 10 --between-ms 10 --duration-ms 3000 --repeats 3 --seed 42
```

Обе реализации получают одинаковые строки, потоки стартуют через общий барьер, за указанный интервал считаются завершённые шаги и перестановки, ввод и печать во время замера отключены

После каждого замера проверяется сохранность записей, выводятся идеальные оценки, число шагов каждого потока и разброс повторов

Параметры — `--help`, результаты и объяснение — [docs/results.md](docs/results.md)
