# Проект

Лабораторная J1 по хранению и обработке информации.
Задание: docs/task_J1.pdf.
Стек: Java 21, Maven, Bouncy Castle, JUnit Jupiter.

# Правила работы

- Объясняй решения на русском языке
- Соблюдай задание и используй понятную архитектуру
- Работай над лабораторной небольшими последовательными этапами
- Перед реализацией этапа кратко объясняй подход
- После изменений запускай сборку и относящиеся к ним тесты
- Не меняй размер RSA-ключей в рабочей реализации: 8192 бит
- Не добавляй зависимости без конкретной необходимости

# Требования J1

- Сервер работает по TCP и принимает ASCII-имя с нулевым байтом в конце
- Коммуникация сервера использует Java NIO и Selector
- Генерация ключей выполняется в отдельном фиксированном пуле потоков
- Размер пула задаётся через командную строку и может превышать число ядер
- Генерирующие потоки не блокируются на передаче данных клиентам
- Для одного имени генерируется одна пара ключей, даже при одновременных запросах
- Ключи и сертификаты сохраняются в оперативной памяти сервера
- Ключ подписи создаётся заранее и читается из файла при старте сервера
- Issuer задаётся для сервера, Subject соответствует имени клиента
- Сервер поддерживает минимум 100 активных соединений
- Учитывай медленных клиентов, разрыв соединений и частичное чтение/запись
- Клиент сохраняет результат в .key и .crt
- Клиент поддерживает задержку чтения и завершение без чтения ответа
- Основной вариант сервера строим на Selector без потока ОС на каждого клиента
